## 1. 项目背景

### 1.1 市场背景

郑州拥有较多高校，存在大学生家教供给；本地家长也有小学、初中、高中阶段的一对一家教需求。现有熟人介绍、社区群和兼职群的主要问题是身份难核实、信息分散、联系方式外泄、价格不透明、服务过程无记录。

本产品提供经过审核的老师信息和经同意展示的家长需求。平台不默认公开联系方式，而是通过付费解锁建立可追溯的联系记录。

### 1.2 产品定位

产品定位为：**郑州本地大学生家教信息展示与付费撮合平台。**

平台连接两类用户：

1. 家长用户：浏览老师、发布家教需求、付费解锁老师联系方式。
2. 老师用户：提交资料审核、浏览家长需求、付费解锁家长联系方式。

第一版提供：

1. 老师信息展示。
2. 家长需求展示。
3. 付费解锁联系方式与完整信息。
4. 老师审核与信息上下架。
5. 基础预约订单、联系解锁记录、评价和问题反馈管理。

平台只提供信息展示、联系方式解锁、预约撮合和服务记录。平台不承诺教学效果，不提供“保分”“保过”“快速提分”“名校必上”等结果承诺。

### 1.3 第一版商业模式

第一版采用“免费基础信息展示 + 付费解锁联系方式”的模式。

| 购买方 | 解锁对象 | 解锁内容 | 单价 | 有效期 |
| --- | --- | --- | --- |
| 家长 | 1 位老师 | 完整资料、联系方式和可沟通时间 | 9.9 元 | 永久；目标信息下架或撤回授权时停止展示 |
| 审核通过老师 | 1 条家长需求 | 完整需求、联系方式和期望沟通时间 | 49.9 元 | 永久；目标需求关闭或撤回授权时停止展示 |

平台主要收益来自家长解锁老师联系方式和老师解锁家长需求联系方式。后续可扩展老师置顶、推荐位和曝光会员，但第一版不开发会员、提现、复杂分账和推广返利。

**解锁服务与授课费用分离。** 9.9 元和 49.9 元仅为信息解锁服务费，不包含家教课时费。第一版不代收老师授课费，也不对老师与家长后续线下授课交易进行分账。

### 1.4 用户角色与权限

| 角色 | 可免费查看 | 可付费解锁 | 关键限制 |
| --- | --- | --- | --- |
| 游客 | 老师公开基础信息 | 不可 | 不展示联系方式；不可购买 |
| 家长 | 老师公开基础信息 | 老师完整信息和联系方式 | 必须登录、完成家长资料、账号正常 |
| 老师 | 家长公开需求信息 | 家长完整需求和联系方式 | 必须登录、完成老师资料、审核通过、账号正常 |
| 管理员 | 后台审核与管理数据 | 不适用 | 只能按权限查看敏感材料和脱敏列表 |

### 1.5 范围与边界

第一版保留微信登录、手机号授权、身份选择、老师审核、老师列表、老师详情、预约订单、评价和问题反馈。

第一版不开发：

- 即时聊天、语音通话、视频通话和直播课。
- 课程包、会员、优惠券、邀请返利和复杂推荐算法。
- 家教授课费的担保交易、提现、自动分账和自动退款。
- 多城市切换、机构老师入驻和地图距离排序。
- 学信网截图、奖学金证书等高门槛材料的强制上传。

## 3. 需求描述

### 3.1 信息展示池与联系方式授权

#### 3.1.1 通用规则

1. 联系方式不能默认公开。
2. 联系方式展示授权必须是独立勾选项，默认不勾选。
3. 勾选项必须展示授权范围、授权对象和隐私政策入口。
4. 用户提交授权后，后端记录 `consent_version`、`consent_at`、`user_id` 和授权状态。
5. 未同意联系方式授权的老师或家长需求不得进入公开展示池。
6. 用户撤回授权、关闭需求或被后台下架后，不允许新的用户继续解锁。
7. 已经解锁的用户可在目标信息有效时长期查看；目标撤回授权、关闭或被封禁后，已解锁页面不再返回联系方式，并展示“该信息已停止展示”。
8. 前端不得根据本地状态判断已支付或已解锁；所有展示权限以服务端返回为准。

#### 3.1.2 老师联系方式授权

老师提交或编辑资料时增加必选项：

> 我同意在家长付费解锁后，向该家长展示我的联系方式。

老师未勾选时，资料可以保存为草稿或待补充，但不得进入老师列表和推荐位。老师勾选授权、审核通过、账号正常且接单状态可用后，才可进入展示池。

#### 3.1.3 家长联系方式授权

家长发布需求时增加必选项：

> 我同意在老师付费解锁后，向该老师展示我的联系方式。

家长未勾选时，不允许发布为公开需求。家长可保存草稿；只有勾选授权、账号正常且需求状态为 `active` 的需求可进入老师端需求列表。

#### 3.1.4 防止联系方式绕过规则

老师个人介绍、教学经历、补充说明、家长学习情况和老师要求等公开文本，不得填写手机号、微信号、二维码、精确门牌地址或其他联系方式。

前后端均应校验以下内容：

- 连续 11 位手机号。
- 微信号引导词及疑似微信 ID。
- 二维码图片。
- 精确到门牌号的地址。

命中规则时，前端提示修改；服务端必须再次拦截，不能仅依赖前端校验。

### 3.2 老师信息展示规则

#### 3.2.1 免费展示字段

家长、老师和游客可查看审核通过老师的公开基础信息。免费详情接口不得返回任何联系方式字段。

| 字段 | 展示规则 |
| --- | --- |
| 头像 | 展示老师本人头像 |
| 展示名称 | 使用“张同学”等展示名；不展示真实姓名 |
| 性别 | 展示 |
| 学校、专业、当前年级 | 展示 |
| 可授课科目、年级、区域、时间 | 展示 |
| 课时费 | 列表展示最低课时费起；详情展示分年级价格 |
| 个人介绍、教学经历 | 各展示前 60 个字符，超出显示省略号 |
| 适合人群标签、平台认证标签 | 展示；认证标签最多 3 个 |
| 评分、评价摘要 | 展示；评价不展示家长敏感信息 |

免费展示时不得返回老师完整手机号、微信号、真实姓名、身份证号、学生证照片、详细住址、认证原图或其他隐私材料。

#### 3.2.2 已解锁展示字段

仅当当前登录用户为家长，且服务端确认该家长已解锁该老师时，老师详情页展示以下完整信息：

1. 完整个人介绍。
2. 完整教学经历。
3. 手机号。
4. 微信号，仅老师主动填写时展示。
5. 可沟通时间。
6. 老师补充说明。

如果老师未填写微信号，不渲染微信号字段；如果老师仅授权手机号，只展示手机号。

#### 3.2.3 联系方式锁定模块

未解锁状态：

- 标题：联系方式已隐藏。
- 说明：为保护双方隐私，解锁后可查看老师联系方式和完整资料。
- 按钮：9.9 元解锁老师联系方式。

已解锁状态：

- 标题：联系方式。
- 字段：手机号、微信号（如有）、可沟通时间、备注说明。
- 页面显示已解锁标记，不再显示支付按钮。

#### 3.3.1 家长需求字段

| 字段 | 是否必填 | 规则 |

#### 3.3.2 免费展示字段

仅审核通过老师可浏览状态为 `active` 的家长需求。需求列表和未解锁详情展示：

1. 家长称呼。
2. 所在区域。
3. 孩子年级。
4. 辅导科目。
5. 期望上课时间。
6. 预算课时费。
7. 孩子学习情况前 60 个字符。
8. 对老师要求前 60 个字符。

未解锁接口不得返回家长完整手机号、微信号、完整需求文本、家庭详细地址、孩子姓名、学校、班级和精确定位。

#### 3.3.3 已解锁展示字段

仅当当前登录用户为审核通过老师，且服务端确认该老师已解锁该需求时，需求详情页展示：

1. 完整需求描述。
2. 手机号。
3. 微信号，仅家长主动填写时展示。
4. 期望沟通时间。
5. 详细上课区域说明，不包含家庭门牌地址。
6. 补充要求。

第一版不展示家庭详细门牌地址。双方后续沟通确认后，由家长自行决定是否提供。

#### 3.3.4 家长需求联系方式锁定模块

未解锁状态：

- 标题：联系方式已隐藏。
- 说明：为保护双方隐私，解锁后可查看家长联系方式和完整需求。
- 按钮：49.9 元解锁家长联系方式。

已解锁状态：

- 标题：联系方式。
- 字段：手机号、微信号（如有）、期望沟通时间、需求补充说明。

### 3.4 付费解锁流程

#### 3.4.1 家长解锁老师流程

1. 家长进入老师详情页，免费查看基础信息。
2. 联系方式模块显示锁定状态和 9.9 元按钮。
3. 用户点击按钮后，服务端校验登录状态、账号状态和当前身份。
4. 未登录时跳转微信登录；当前身份不是家长时提示“请切换为家长身份后操作”。
5. 服务端查询该家长是否已解锁此老师。
6. 已解锁时直接返回已解锁信息，不创建支付订单，不重复扣费。
7. 未解锁时，服务端确认老师仍为审核通过、可展示、未封禁且已授权联系方式展示。
8. 服务端创建金额为 9.90 元的支付订单，返回支付参数。
9. 微信支付成功通知由后端验签处理；后端写入解锁记录并授予永久解锁权益。
10. 前端重新请求详情和解锁状态，展示完整老师信息和联系方式。

#### 3.4.2 老师解锁家长需求流程

1. 老师进入家长需求详情页，免费查看基础需求。
2. 联系方式模块显示锁定状态和 49.9 元按钮。
3. 用户点击按钮后，服务端校验登录状态、账号状态和当前身份。
4. 未登录时跳转微信登录；当前身份不是老师时提示“请切换为老师身份后操作”。
5. 服务端校验老师审核状态必须为 `approved`。
6. 未审核通过时提示“老师资料审核通过后才可以解锁家长联系方式”。
7. 服务端查询该老师是否已解锁此需求；已解锁时直接展示，不重复扣费。
8. 未解锁时，服务端确认需求状态为 `active`、家长账号正常且已授权联系方式展示。
9. 服务端创建金额为 49.90 元的支付订单，返回支付参数。
10. 微信支付成功通知由后端验签处理；后端写入解锁记录并授予永久解锁权益。
11. 前端重新请求详情和解锁状态，展示完整需求和联系方式。

#### 3.4.3 解锁确认弹窗

点击解锁按钮后必须弹出确认弹窗。弹窗包含：

- 解锁对象展示名。
- 解锁服务名称。
- 应付金额。
- 说明：“为保护双方隐私，联系方式需付费解锁后查看。”
- 提示：“联系方式属于虚拟信息服务，解锁成功后不支持无理由退款。”
- “确认支付”和“取消”按钮。

按钮文案固定为：

- 家长端：9.9 元解锁老师联系方式。
- 老师端：49.9 元解锁家长联系方式。

不得使用“买手机号”“卖信息”“购买用户资料”“低价获取联系方式”等文案。

### 3.5 支付、权益与退款规则

#### 3.5.1 支付规则

生产环境使用微信支付。支付金额以服务端创建订单时的价格快照为准，前端不得传入、修改或信任支付金额。

| 场景 | 支付成功 | 支付失败 | 用户取消 |
| --- | --- | --- | --- |
| 家长解锁老师 | 创建解锁记录，展示完整老师信息 | 不展示联系方式 | 不展示联系方式 |
| 老师解锁需求 | 创建解锁记录，展示完整家长需求 | 不展示联系方式 | 不展示联系方式 |

微信支付回调必须由服务端验签、幂等处理。前端支付结果只用于刷新页面，不能作为解锁权限依据。

#### 3.5.2 开发环境 mock 支付

开发环境可以提供 mock 支付接口，用于联调解锁页面、记录和权限判断。mock 支付必须满足：

1. 仅在 `dev` 或 `test` 环境启用。
2. 接口、页面和日志明确标注“开发环境 mock 支付”。
3. mock 支付成功后仍由服务端创建解锁记录。
4. 生产环境必须关闭 mock 支付接口。

#### 3.5.3 重复购买与有效期

1. 同一购买用户不能重复购买同一老师或同一需求。
2. 服务端创建支付订单前必须查询已支付且有效的解锁记录。
3. 已解锁时返回 `unlockStatus = unlocked`，不创建新订单。
4. 第一版解锁权益为永久有效，`expired_at` 为空。
5. 未来如改为 30 天有效，只修改权益规则；历史已永久解锁记录不自动失效。

#### 3.5.4 退款与异常处理

第一版不做自动退款。支付前必须明确展示“解锁成功后不支持无理由退款”。

如联系方式无效、信息与页面描述不符或存在恶意骚扰，用户可提交问题反馈。后台人工核实后可记录退款、补偿、下架或封禁处理结果；自动退款能力不属于第一版范围。

### 3.6 老师课时定价规则

#### 3.6.1 平台价格区间

第一版采用强控制价格。老师仅能为已选择的授课年级填写对应推荐区间内的价格。

| 年级单元 | 最低价格 | 最高价格 | 单位 |
| --- | --- | --- | --- |
| 小学 1 至 3 年级 | 50 元 | 60 元 | 元/小时 |
| 初一 | 60 元 | 80 元 | 元/小时 |
| 初二 | 80 元 | 100 元 | 元/小时 |
| 初三 | 100 元 | 120 元 | 元/小时 |
| 高中 | 120 元 | 150 元 | 元/小时 |

高中第一版使用统一价格区间，不再区分高一、高二、高三。小学 4 至 6 年级和其他未配置年级，在第一版不允许作为独立可收费年级发布；需要运营确认后新增价格规则。

#### 3.6.2 老师分年级定价

1. 老师至少选择 1 个可授课年级单元。
2. 每个已选择年级单元必须设置 1 个整数课时费。
3. 价格必须在当前启用的 `pricing_rule` 最低价和最高价之间。
4. 老师可教多个年级时，必须分别设置价格。
5. 老师列表展示其最低有效课时费，例如“50 元/小时起”。
6. 老师详情展示“年级单元 - 课时费”明细。
7. 后台修改价格规则后，仅影响后续老师资料保存和后续家长预算提示；不自动改写历史老师价格。

示例：

| 年级单元 | 老师课时费 |
| --- | --- |
| 小学 1 至 3 年级 | 50 元/小时 |
| 初一 | 70 元/小时 |
| 初二 | 90 元/小时 |
| 初三 | 110 元/小时 |
| 高中 | 130 元/小时 |

#### 3.6.3 价格校验提示

第一版强控制价格，超出区间时不允许提交，并提示：

> 当前年级课时费需在平台建议范围内填写。

后续如改为弱控制，可允许超出区间并提示“当前价格超出平台建议范围，可能影响家长选择”；第一版不采用弱控制。

### 3.7 家长需求预算规则

1. 家长发布需求时必须选择孩子年级单元并填写整数预算课时费。
2. 页面根据 `pricing_rule` 实时展示建议范围。
3. 家长预算在区间内时正常提交。
4. 家长预算低于区间最小值时允许提交，但提示“预算较低，可能影响老师响应”。
5. 家长预算高于区间最大值时允许提交，但提示“预算高于平台参考范围，请确认填写无误”。
6. 家长需求列表展示预算，例如“预算 80 至 100 元/小时”或“预算 90 元/小时”。
7. 家长需求不得填写或展示家庭详细门牌地址。

### 3.8 预约订单、联系记录与问题反馈

#### 3.8.1 与现有预约订单的关系

1. 付费解锁是信息服务，不创建预约订单。
2. 预约订单是家长向老师提交具体上门授课预约的记录。
3. 已解锁不代表双方已达成授课安排。
4. 未解锁时，家长仍可按现有平台规则提交预约；预约流程中的地址保护规则继续有效。
5. 现有订单状态流转、评价和投诉功能保持不变。

#### 3.8.2 联系方式相关问题反馈

问题反馈新增原因：

1. 手机号无法联系。
2. 微信号不存在。
3. 信息与页面描述不符。
4. 对方恶意骚扰。
5. 其他问题。

后台可查看关联的解锁记录、目标信息状态和历史投诉。多次被投诉的老师或家长需求可被下架；被封禁用户不得继续被解锁，也不得解锁他人信息。

### 3.9 我的解锁记录

家长和老师均可进入“我的解锁记录”。页面根据当前身份显示对应记录：

| 当前身份 | 记录类型 | 对象 |
| --- | --- | --- |
| 家长 | `teacher_contact` | 已解锁老师 |
| 老师 | `parent_contact` | 已解锁家长需求 |

每条记录展示：

1. 解锁对象名称。
2. 解锁类型。
3. 解锁金额。
4. 解锁时间。
5. 当前展示状态。
6. 查看详情按钮。

目标信息仍有效时，点击“查看详情”进入已解锁详情。目标信息已关闭、撤回授权或被下架时，记录保留，但详情页只展示“该信息已停止展示”，不返回联系方式。

### 3.10 后台管理要求

#### 3.10.1 解锁记录管理

后台新增“解锁记录”页面，列表字段：

1. 解锁记录 ID。
2. 购买用户 ID。
3. 购买用户身份。
4. 被解锁对象 ID。
5. 被解锁对象类型。
6. 支付金额。
7. 支付状态。
8. 解锁状态。
9. 解锁时间。
10. 支付订单号。

筛选条件：购买用户身份、解锁类型、支付状态、解锁状态、时间范围、手机号后四位。

后台列表不得展示完整手机号、微信 openid、完整家庭地址或孩子敏感信息。手机号检索仅允许后四位；展示时必须脱敏。

#### 3.10.2 家长需求管理

后台新增“家长需求”页面，可按状态、区域、年级、科目、创建时间和手机号后四位筛选。管理员可以：

- 查看公开需求及完整后台字段。
- 关闭违规、过期或无效需求；关闭必须填写原因。
- 下架存在多次投诉的需求。
- 查看与该需求关联的解锁记录和问题反馈。

#### 3.10.3 价格规则管理

后台新增“价格规则”页面。管理员可查看、启用或修改年级价格规则。修改字段：年级单元、最低价格、最高价格、启用状态。

校验规则：

1. 最低价格和最高价格均为正整数。
2. 最低价格必须小于或等于最高价格。
3. 同一年级单元只能有 1 条启用规则。
4. 规则修改必须记录管理员、修改前值、修改后值和操作时间。

### 3.13 隐私、安全与风控规则

1. 上线前必须由平台法务或合规负责人复核联系方式授权文案、隐私政策、付费说明和支付退款规则。
2. 联系方式授权与用户协议、隐私政策同意分开记录，不能用一个泛化勾选代替。
3. 联系方式在数据库中加密存储，日志、埋点和后台列表仅显示脱敏值。
4. 未解锁详情接口不返回联系方式字段，而不是返回空字符串后由前端隐藏。
5. 解锁详情接口必须在服务端实时校验购买方身份、有效权益、目标状态和授权状态。
6. 普通用户不能查看学生证、身份证、完整地址、孩子姓名、学校、班级、微信 openid。
7. 被冻结或封禁用户不能发布、购买、解锁或被展示为可解锁目标。
8. 敏感材料查看、支付结果写入、解锁权益授予、需求关闭和价格规则修改必须记录操作日志。
9. 解锁记录、支付订单和微信支付回调必须具备幂等键，避免重复扣款和重复授予权益。
10. 发现联系方式无效、资料不符或骚扰投诉时，后台可以关闭信息、限制账号或人工处理退款；第一版不自动退款。

### 3.14 验收标准

#### 3.14.1 信息展示与解锁

1. 家长可以免费浏览老师基础信息。
2. 家长未付费前不能查看老师联系方式和完整资料。
3. 家长支付 9.9 元后，可以查看指定老师完整信息和联系方式。
4. 家长重复查看已解锁老师时，不重复扣费。
5. 审核通过老师可以免费浏览家长基础需求。
6. 老师未付费前不能查看家长联系方式和完整需求。
7. 审核通过老师支付 49.9 元后，可以查看指定家长完整需求和联系方式。
8. 老师重复查看已解锁家长需求时，不重复扣费。
9. 未审核通过老师不能解锁家长信息。
10. 被冻结或封禁用户不能解锁联系方式，也不能作为可解锁目标展示。
11. 未同意联系方式展示授权的老师和家长需求不进入展示池。
12. 目标撤回授权、关闭或被下架后，不再向已购用户返回联系方式。

#### 3.14.2 支付与记录

1. 付费前展示金额、隐私提示和退款提示。
2. 支付成功后由服务端创建解锁记录。
3. 支付失败或用户取消后不展示联系方式。
4. 前端不能通过本地缓存伪造已支付状态。
5. 同一用户不能重复购买同一对象。
6. 开发环境 mock 支付与生产微信支付清晰隔离。
7. 后台可以查询全部解锁记录，手机号必须脱敏展示。

#### 3.14.3 价格规则与需求

1. 老师课时费按年级价格规则填写并由服务端校验。
2. 小学 1 至 3 年级价格范围为 50 至 60 元/小时。
3. 初一价格范围为 60 至 80 元/小时。
4. 初二价格范围为 80 至 100 元/小时。
5. 初三价格范围为 100 至 120 元/小时。
6. 高中价格范围为 120 至 150 元/小时。
7. 老师可为多个年级分别设置课时费。
8. 家长发布需求时能看到与孩子年级匹配的预算参考范围。
9. 后台可以配置或代码初始化价格规则。
10. 家长需求免费展示不包含详细地址、孩子姓名、学校和班级。

#### 3.14.4 回归与安全

1. 原有微信登录、身份选择、手机号授权、老师审核、老师列表、老师详情、预约订单、评价和问题反馈功能不受影响。
2. 微信开发者工具可以正常编译。
3. 支付、解锁、授权、需求关闭、封禁和价格规则修改均有服务端日志。
4. 未授权接口、未解锁接口和被封禁账号不能获取联系方式。

## 4. 建议埋点

### 4.1 埋点原则

1. 不上报完整手机号、微信号、详细地址、孩子姓名、学校、班级、身份证号和学生证原图。
2. 使用内部用户 ID、老师 ID、需求 ID、解锁记录 ID 和支付订单号作为分析标识。
3. 支付金额、支付状态和解锁状态以服务端事件为准；前端埋点仅用于漏斗分析。
4. 埋点失败不得影响支付、解锁、预约和审核主流程。

### 4.2 公共属性

| 字段 | 说明 |
| --- | --- |
| `event_time` | 事件发生时间 |
| `user_id` | 当前内部用户 ID；未登录为空 |
| `current_role` | `guest`、`parent`、`teacher` |
| `page_name` | 当前页面标识 |
| `page_source` | 上一页面或入口 |
| `environment` | `dev`、`test`、`prod` |
| `app_version` | 小程序版本 |
| `city_code` | 服务城市标识，第一版固定郑州 |

### 4.3 付费解锁埋点

| 事件名 | 触发时机 | 建议属性 | 指标 |
| --- | --- | --- |
| `teacher_unlock_module_view` | 家长看到老师锁定模块 | `teacher_id`、`unlock_status` | 老师详情解锁曝光 |
| `requirement_unlock_module_view` | 老师看到需求锁定模块 | `requirement_id`、`unlock_status` | 家长需求解锁曝光 |
| `unlock_click` | 点击解锁按钮 | `target_type`、`target_id`、`amount` | 解锁意图 |
| `unlock_confirm_view` | 解锁确认弹窗曝光 | `target_type`、`amount` | 确认页到支付转化 |
| `unlock_pay_create_result` | 创建支付订单结果 | `target_type`、`amount`、`result`、`fail_reason` | 下单成功率 |
| `unlock_pay_result` | 支付完成、失败或取消 | `target_type`、`amount`、`result` | 支付成功率、取消率 |
| `unlock_granted` | 服务端授予权益 | `unlock_record_id`、`target_type`、`amount` | 实际解锁收入 |

### 4.6 核心看板与漏斗

第一版运营看板优先展示：

1. 老师列表曝光、老师详情曝光、家长解锁点击、家长支付成功、家长解锁收入。
2. 家长需求发布数、需求详情曝光、老师解锁点击、老师支付成功、老师解锁收入。
3. 老师审核通过数、可展示老师数、可展示需求数、联系方式授权率。
4. 解锁成功率、支付取消率、重复购买拦截数、问题反馈率、人工处理时长。
5. 按年级单元统计老师价格分布、家长预算分布与解锁转化率。

核心漏斗：

```text
家长：老师列表 -> 老师详情 -> 解锁模块曝光 -> 点击解锁 -> 创建支付订单 -> 支付成功 -> 查看完整资料

老师：家长需求列表 -> 需求详情 -> 解锁模块曝光 -> 点击解锁 -> 创建支付订单 -> 支付成功 -> 查看完整需求
```
