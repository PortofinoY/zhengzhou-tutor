# MVP 验收清单

## 登录

- 微信登录接口会按 `code` 创建或更新用户。
- 用户可绑定中国大陆手机号。
- 用户可在家长和老师身份间切换。

## 老师入驻

- 小程序提供老师入驻表单。
- 老师头像和学生证照片通过登录鉴权后的上传接口持久化，不保存微信临时文件路径。
- 上传仅支持 JPG、JPEG、PNG，单张不超过 10 MB；不合法文件不写入磁盘。
- 后端校验真实姓名、学校、专业、头像、认证材料、授课科目、年级、区域、时间和课时费。
- 提交后老师状态为 `pending`。
- 后台可审核通过或驳回；驳回必须填写原因。
- 通过后老师可出现在列表，驳回和封禁不展示。

## 老师列表

- 列表接口只返回审核通过、可接单、未封禁老师。
- 支持科目、年级、区域、学校、价格、性别和关键词筛选。
- 支持综合、价格低到高、评分高到低、最新入驻排序。

## 预约和订单

- 家长必须登录、绑定手机号、账号正常才可下单。
- 家长不能预约自己的老师身份。
- 初始订单状态为 `pending_teacher`。
- 老师可接受或拒绝待确认订单。
- 老师接受后状态为 `pending_class`，拒绝后为 `rejected`。
- 老师可开始上课、完成授课；家长可确认完成。
- 已完成、已取消、已拒绝、已关闭订单不能恢复或取消。
- 老师接受前无法看到详细地址。

## 评价

- 家长只能评价自己的已完成订单。
- 每个订单只能评价一次。
- 可见评价展示在老师详情页，隐藏评价只保留后台。

## 投诉

- 家长或老师可对相关订单发起投诉。
- 投诉图片最多 6 张，必须先上传为永久 URL；上传期间不可提交投诉。
- 投诉后订单状态为 `complaint`，记录原状态。
- 后台可设为处理中或已处理，并填写处理结果。

## 后台

- 管理员账号密码登录。
- 连续 5 次失败锁定 30 分钟。
- 后台包含数据看板、老师审核、老师管理、家长管理、订单管理、投诉管理、评价管理。

## 生产安全基线

- 体验版和正式版后端地址必须是明确配置的 HTTPS 地址，不得回退本机。
- 生产环境缺少 `TUTOR_TOKEN_SECRET`、`WECHAT_APPID` 或 `WECHAT_SECRET` 时拒绝启动。
- 生产环境强制关闭 mock 能力和演示数据，不自动创建管理员或测试业务数据。
- 老师接受订单前，订单列表和详情均不返回家长完整手机号及详细地址。
- 生产环境调用 mock 支付接口返回明确错误，且不生成解锁记录。
- `.env`、数据库运行文件和用户上传文件不得进入 Git 仓库。

## MySQL 数据层

- development/test 默认可使用 JSON；production 配置 JSON 时拒绝启动。
- production 缺少任一 MySQL 连接变量、连接失败或迁移版本低于 7 时拒绝提供服务。
- 服务启动不自动建表，不自动回退 JSON，不自动导入演示数据。
- MySQL 金额字段使用整数分；API 继续按当前元单位返回，保持前端兼容。
- 订单创建和状态流转同时写入 `order_status_logs`，任一步失败则事务回滚。
- 上传成功同时记录 `uploaded_files` 元数据；本阶段文件本体仍保存在本地开发目录。
- JSON 导入默认 dry-run，正式写入必须显式使用 `--execute`。
- 重复导入保持原 ID，不产生重复行；源 JSON 不会自动删除。
- MySQL 管理员初始化使用事务，重复用户名或手机号明确失败。
- 迁移日志和核验日志不得打印手机号、openid、密码哈希、Token 或认证图片地址。
